# Universal DB

Экспериментальный прототип хранилища на Rust: граф, история событий, версии состояния и базовые транзакции.

**Статус: исследовательский прототип, не production-ready.** Код показывает несколько независимых идей, но пока не гарантирует ACID, изоляцию транзакций, crash consistency или безопасность файлового доступа для недоверенных идентификаторов.

## Запуск

Требуются актуальный Rust stable и Cargo.

```sh
cargo check --locked --all-targets
cargo test --locked
cargo run --locked
```

Демонстрационный `src/main.rs` создаёт временное JSON-хранилище в `.test_db_phase4` и удаляет его после демонстрации. Запускайте программу только в изолированной рабочей директории, если там уже могут быть пользовательские данные.

## Текущие компоненты

- `models.rs`, `store.rs` — модели, хранилище графа, состояния и событий.
- `graph_algorithms.rs`, `indexing.rs` — обходы графа и индексы в памяти.
- `persistence.rs` — файловое **JSON-хранилище** (RocksDB не подключена).
- `transactions.rs` — группировка событий и демонстрационные стратегии конфликтов; это не транзакции ACID.
- `concurrency.rs`, `benchmarks.rs`, `formal_verification.rs` — исследовательские модели параллелизма, измерений и проверок согласованности.

### Перед серьёзным применением

Проверьте безопасное кодирование идентификаторов файлов (сейчас имена файлов формируются из ID), атомарную запись/восстановление, fsync, права доступа, журналирование, уникальность идентификаторов, повторное применение событий, тесты параллелизма, лимиты памяти и корректность конкурентных конфликтов. Нельзя считать сообщения демонстрационной программы доказательством прохождения этих проверок.

CI проверяет компиляцию и имеющиеся тесты, но не является подтверждением надёжности базы данных.
